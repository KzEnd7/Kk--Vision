# KK Vision

Personal bilingual resume site for Kangkai Sun / 孙康凯.

## Local Preview

Open `index.html` directly, or run:

```bash
python3 -m http.server 5173
```

Then visit:

```text
http://127.0.0.1:5173/
```

## GitHub Pages

This is a static site. It can be published from the repository root with GitHub Pages.
